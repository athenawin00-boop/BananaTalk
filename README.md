# BananaTalk

실리태번(SillyTavern) 채팅창 옆에 띄워 두는 **보조 메신저 창**입니다.
롤플레이 중에 뭔가 찾아보거나 물어볼 게 있을 때, 다른 브라우저 창을 오가지 않고 바로 묻는 용도입니다.

- 메인 API와 **별개의 연결 프로필**로 동작합니다.
- 메인 채팅에는 **아무 영향이 없습니다.** 채팅 파일·캐릭터 카드·월드 인포를 건드리지 않습니다.
- 기록은 **채팅 파일마다 따로** `data/<사용자>/user/files/bananatalk-<키>.json` 에 저장됩니다.

## 설치

확장 → 확장 설치 → 이 저장소 주소 입력:

```
https://github.com/athenawin00-boop/BananaTalk
```

필요: **Connection Manager**(연결 프로필 관리자) 확장이 켜져 있어야 하고, 쓸 연결 프로필을 하나 만들어 두어야 합니다.

## 사용

| 어디서 | 무엇 |
|---|---|
| 입력창 왼쪽 💬 버튼 | 창 열기/닫기 |
| 마법봉(확장) 메뉴 → BananaTalk | 창 열기/닫기 |
| `/bananatalk 질문` (`/btalk`) | 창을 열고 질문 전송, 답장 반환 |
| 메인 채팅 글자 드래그 → "물어보기" | 선택한 문장을 인용해서 질문 |
| 머리줄 드래그 / 모서리 | 창 이동 / 크기 조절 (기기별로 기억) |
| ⚙ | 설정을 창 안에서 바로 |
| ☰ | 대화 목록: 이름 바꾸기, 비우기, 삭제, 전부 삭제 |
| ＋ | 새 대화 스레드 |

### 모드 (대화마다 따로 선택)

| 모드 | 넣는 것 | 역할 |
|---|---|---|
| 캐릭터 | 캐릭터 카드 · 페르소나 · 최근 대화 (· 월드 인포) | 캐릭터 말투로 메신저 답장 |
| 연출 상의 | 위와 같음 | OOC 조수. 흐름 분석, 다음 전개 제안, 설정 확인 |
| 어시스턴트 | 없음 | 일반 질의응답 |

### 설정

- **생성**: 기본 모드, 스트리밍, 최대 토큰(강제), 최소/최대 글자 수(프롬프트 지시 — 보장은 안 됨), 추가 지시
- **맥락**: 최근 메시지 수, 메시지당 최대 글자(넘치면 앞 30%·끝 70%만), 카드/페르소나/월드 인포 포함 여부
- **모양**: 테마(실리태번 따라가기·노랑·파랑·다크·민트), 투명도(15~100%), 마우스 올리면 선명하게, 글자 크기, 아바타, 창 그림자 끄기, "물어보기" 버튼, 모바일 하단 시트

모바일에서는 입력창 위에 하단 시트로 붙고, 위쪽 손잡이로 높이를 조절합니다.

## 저장 구조

```json
{ "v": 1, "chatKey": "c:<아바타>:<채팅파일>", "label": "...", "active": "<스레드id>",
  "threads": [ { "id": "...", "title": "", "mode": "character", "createdAt": 0,
                 "messages": [ { "role": "user", "text": "...", "ts": 0 } ] } ] }
```

파일 이름은 채팅 키의 해시입니다. 창 위치·크기와 설정 묶음 펼침 상태는 브라우저 `localStorage`에, 나머지 설정은 `settings.json`의 `bananatalk` 키에 저장됩니다.
